# 🌾 Farmer Saathi - Smart Farming Platform

**Empowering Modern Farmers with AI-Powered Agricultural Solutions**

Farmer Saathi is a comprehensive NextJS agritech platform designed to revolutionize farming through artificial intelligence, data-driven insights, and community collaboration. Built for the GenAI hackathon, this platform addresses real-world agricultural challenges with cutting-edge technology.

## 🚀 Live Demo

Visit the platform: [Farmer Saathi](http://localhost:5000)

## 🌟 Key Features

### 🤖 AI-Powered Tools
- **Crop Advisory**: Get personalized farming advice based on crop type, location, season, and soil conditions
- **Crop Pricing & Markets**: Real-time market insights and optimal pricing recommendations
- **Crop Planning Assistant**: AI-driven crop recommendations with financial projections

### 📊 Smart Management
- **Farm Inventory**: Track seeds, fertilizers, equipment, and harvest quantities
- **Farm Task Manager**: Organize daily activities with priority-based task management

- **Farmer Stories**: Share farming journeys and success stories
- **Farming Challenges**: Participate in sustainable farming competitions
- **Agricultural Events**: Discover local and national farming events

### 💬 Intelligent Assistant
- **AI Chatbot**: 24/7 farming support with voice commands and multilingual support
- **Voice Navigation**: Hands-free interaction for busy farmers
- **Smart Recommendations**: Context-aware suggestions based on farming patterns

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn
- Firebase account
- Google Gemini API key

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/your-username/farmer-saathi.git
cd farmer-saathi
```

2. **Install dependencies**
```bash
npm install
```

3. **Environment Setup**
Create `.env.local` file:
```env
GOOGLE_GENAI_API_KEY=your_gemini_api_key
NEXT_PUBLIC_FIREBASE_API_KEY=your_firebase_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_domain
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
```

4. **Run the development server**
```bash
npm run dev
```

5. **Open your browser**
Navigate to `http://localhost:5000`
